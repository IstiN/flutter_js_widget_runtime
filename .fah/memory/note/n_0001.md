# Note: n_0001

Web preview architecture (agreed with flutter_agent repo orchestrator, 2026-08-30): fa1.dev/widgets card iframes point at the GitHub Pages runner https://istin.github.io/flutter_js_widget_runtime/preview/?widget=<id>&theme=dark (contract fixed; the old DOM/CSS shim was deleted). Runner = example/lib/preview.dart in flutter_js_widget_runtime, deployed by .github/workflows/pages.yml (landing site/index.html at root, runner at /preview/, base-href /flutter_js_widget_runtime/preview/). Widget sources come from raw.githubusercontent.com/IstiN/fa_widgets/main/widgets/<id>/ (?base= overrides). fetch gated by manifest network flag; js3dHost attached (flutter_cube works on web, GLB/flame_3d don't — no flutter_gpu). Platform widgets (calendar/contacts/health/homekit) need host bridges and error out on web by design. Known fa_widgets bugs reported: focus-timer uses node type 'linearProgress' (should be 'linearProgressIndicator'), stocks API has no CORS headers.
