# Note: n_0014

Layout contract (agreed 2026-08-30 with flutter_agent orchestrator after the focus-timer BOTTOM OVERFLOWED incident): hosts embed widgets at arbitrary heights (~150px landing cards, panels) — a widget's ROOT node should be scrollable (listView shrinkWrap: false + padding, or scroll) unless content provably fits ~150px. The jsr renderer deliberately does NOT auto-wrap the root in a scroll view; scrollability is the widget's job. Recorded in AGENTS.md + js-widget-authoring SKILL.md (commit 8ae8f83). fa_widgets-side catalog audit is the orchestrator's zone (they fixed focus-timer in 7784c05). Note: flChart pie visually overshoots its sizedBox ~20 logical px upward — give listView roots extra top padding (used [16,40,16,24] in pomodoro).
