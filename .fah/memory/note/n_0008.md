# Note: n_0008

Widgets declare platform support via the manifest `platforms` field; fa1.dev does not iframe widgets whose platforms is non-empty and lacks 'web', marking them 'runs in the Fa app' instead (calendar, contacts, health, homekit, stocks are app-only).
