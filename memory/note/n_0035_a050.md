# Note: n_0035_a050

iOS player no-sound root cause: the fah/mic channel sets AVAudioSession to .record, which mutes all output and survives setActive(false); fixed host-side in flutter_agent PR #227 (micRestorePlaybackSession, mixWithOthers:false); JS side always uses autoPlay:false so iOS autoplay policy is not involved.
