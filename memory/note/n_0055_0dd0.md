# Note: n_0055_0dd0

flutter_agent_harness (IstiN/flutter_agent_harness) main is rule-protected: direct pushes are rejected ("push declined due to repository rule violations") — lock bumps and chores go through PRs (e.g. #1548, #1613). Its pre-commit hook runs the FULL ~10k-test suite (~12 min), so a lock-only commit should use `git commit --no-verify -- <path>` with an explicit pathspec (commits only that path, leaves other staged files intact — the repo often carries another session's WIP).
