# Note: n_0085_e9b5

Flutter GPU THREE directional shadow sampling must flip V only in the MAIN pass shadow matrix (`threeShadowSamplingMatrix`: negate row-Y coefficients 1/5/9 and set 13 = 1−13); the shadow pass keeps the original WebGL-style matrix for clip rendering. Impeller render targets use top-left texel UVs. Without this split, a player-following shadow camera produces mirrored/drifting shadows; fixed-camera W-step screenshots verified world-anchored shadows at ~60 FPS, and the macOS R1 GPU golden was updated. Separate shadow/main command buffers remain required.
