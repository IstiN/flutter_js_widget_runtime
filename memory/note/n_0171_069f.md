# Note: n_0171_069f

test/js_three_batch_lod_interactive_fps_test.dart 'sustained pointermove storm' bound: raycastCalls <= 2*stormFrames+4 (relaxed in 9b8d892 from hard 2*stormFrames). The dragThrottleHover throttle's leading edge fires on >=33ms REAL elapsed (performance.now is wall time in QuickJS, not the fake-async clock), so on loaded CI runners every storm frame legitimately yields leading+trailing (61 observed for 30 frames). The regression signature the guard protects against is 1 raycast per event (150); values ~60 are legitimate. Do not re-chase as a coalescing regression.
