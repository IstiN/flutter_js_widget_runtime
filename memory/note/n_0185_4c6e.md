# Note: n_0185_4c6e

ANGLE-1B QuickJS engine constraint: there is NO queueMicrotask global in the JS sandbox — deferred work must use Promise.resolve().then() (the runtime's established pattern, cf. _scheduleCanvasRefresh). The per-task render-envelope batching in tool/three/src/native_renderer.js _emit() relies on this; a regression here kills every renderer.render (silent 'render failed: queueMicrotask is not defined' in widget status, e.g. three-cinematic-showcase). Related contract changes that shipped with the fps raid (commit 0695d64): envelope batching merges same-task renders into ONE bridge crossing (appliedEnvelopeCount collapses; frameCommands inside are all decoded — submittedFrameCount still counts frames), pumpThreeExampleHealthy targetFrames default is 2, three_visual_coverage pins 304 registry entries (303 official + custom cinematic, which is exempt from the visual corpus loop), and the probe boot accepts render-on-demand widgets (presented>=1 stable for 3s).
