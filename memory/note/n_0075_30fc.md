# Note: n_0075_30fc

The legacy/fallback VoxelPainter topological ordering contract still applies when BSP is disabled or automatically falls back: exact far-to-near average-depth is only the initial order; retain every nonzero perspective-correct depth relation for real positive-area overlaps (including average-correct pairs), use SAT only for screen-disjoint rejection, and reuse the order cache only for an identical camera, viewport and visible-chunk set. Dynamic meshes merge independently.
