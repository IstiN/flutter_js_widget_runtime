# Note: n_0086_3c03

Native THREE Terrain Raycast pointermove was 3–6 FPS despite 120 FPS idle and ~0.1 ms GPU frames because upstream Raycaster scanned all 130,050 terrain triangles per event. tool/three/src/native_raycast_bvh.js now caches a BVH for large indexed single-material meshes, filters candidates, then delegates final triangle/UV/normal/material tests to upstream _computeIntersections and restores faceIndex. Attribute/array identity + versions invalidate; morph/skinned/non-indexed/material-array/bounded-draw-range use stock fallback. QuickJS regression covers 40 exact hits, face ids, needsUpdate rebuild and fallback; release macOS synthetic 125 Hz pointermove now holds ~120 FPS. Web bundle is unchanged.
