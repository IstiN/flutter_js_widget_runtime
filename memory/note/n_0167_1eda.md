# Note: n_0167_1eda

R1 native_renderer gotcha: the lowered-shader feedback-invariant check (`shaderMap.renderTarget === this._renderTarget` around the copyShaderFlags pass-through path) can match undefined===undefined for plain textures on the screen pass, unbinding material.map → mesh renders the white 1x1 fallback. Widget-lane workaround (no engine edit): give display textures an inert sentinel `texture.renderTarget = { jsrSentinel: true }` so the equality never matches. Precedent: tool/three_example/degrades/texture3d_slice2d.mjs (webgl_texture3d_partialupdate white-square fix).
