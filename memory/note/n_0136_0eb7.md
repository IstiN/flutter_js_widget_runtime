# Note: n_0136_0eb7

js_widget_runtime JsRafScheduler lifecycle contract (do not re-break): dispose() = permanent lane death (late RAF from a QuickJS FFI-callback tick is DROPPED — prevents "animation still running after tree disposed" leaks); reset() = full revival (clears the disposed flag). Every backend run() must reset timers via JsWidgetBridge.resetForRun() (NOT bridge.dispose()) because run() reuses the bridge across widget reloads — quickjs/flutter_js/isolate/web backends all do this now. debugStopTimers stays a soft stop. Scheduler is lifecycle-aware: with framesEnabled==false (app hidden) requests queue; a WidgetsBindingObserver restarts the ticker on resume (a Ticker started while hidden is active-but-never-ticks → next requestFrame would double-start it). Regression tests: test/js_widget_bridge_test.dart JsRafScheduler group (4 tests).
