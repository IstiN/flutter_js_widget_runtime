# Note: n_0156_c3fe

webgl_batch_lod_bvh (three-batch-lod-bvh) known-good contract: prepare.mjs facadeWraps.BatchedMesh keeps closest-128 instances at base LOD0 (2097152 tris, 10 draws); the degrade's simplifyGeometriesByErrorLOD must share the SOURCE geometry at every LOD level. Building separate variant geometry ids (procedural TorusKnot reduced-res variants) breaks R1: instances render mixed variant ranges (570560/493568 tris) and the widget never presents in the mac app (backendReady stays 0; in-process widget tests still pass, so only in-app captures reveal it). Also: the module calls addInstance with a BASE INDEX (random*10), and LOD variants claim extra geometry ids, so index→id mapping corrupts silently.
