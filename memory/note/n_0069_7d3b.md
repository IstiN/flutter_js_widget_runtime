# Note: n_0069_7d3b

CRAP thresholds are one-way ratchets. Fa Craft uses an absolute ceiling of 16 in package.json; run `npm run hooks:install` after cloning to select `.githooks/pre-commit`, which compares the STAGED threshold against HEAD (decreases allowed, increases rejected) and runs `npm run crap`. The runtime keeps its stricter crap4dart threshold of 12, and `scripts/pre-commit` likewise rejects staged threshold increases above HEAD or 16.
