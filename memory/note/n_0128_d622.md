# Note: n_0128_d622

Release capture binary must be built with -t lib/screenshot.dart (example/lib/screenshot.dart has the JSR_OUT/JSR_WIDGET/JSR_EXTRA_WAIT harness main()). Building -t lib/three_example.dart produces the owner's sidebar switcher app instead, which ignores JSR_* env vars. Capture loop: pkill -x js_widget_runtime_example, then env JSR_ISOLATE=1 JSR_WIDGET=<id> JSR_OUT=<png> JSR_EXTRA_WAIT=14 JSR_SWITCH_LOG=true <binary>, read THREE performance + THREE diagnostics lines from output.
