# Note: n_0054_5ece

fa_widgets catalog icon contract (fa_widgets#11, fixed 87d6bed): the client resolves manifest `icon` against the REPO mirror raw.githubusercontent.com/IstiN/fa_widgets/main/widgets/<id>/<icon>, so every external widget's pinned icon must be committed at widgets/<id>/. `dart run bin/fa_widgets.dart fetch` now mirrors it from vendor/external/<id>/ (pinned bytes, overlay 'icon' key wins over source manifest, refreshes on drift), the validator errors when the mirror is missing, and publish.yml commits mirrors post-fetch. A pin bump that changes the icon is picked up by re-running fetch.
