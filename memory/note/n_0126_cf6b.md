# Note: n_0126_cf6b

GLBufferAttribute draw-range lane (webgl_buffergeometry_glbufferattribute): R1 uploads the full point set ONCE and moves drawRange through a non-instanced DRAW_BATCH part (offset/count in vertex space). The lane MUST stay non-indexed: prepareIndices used to materialize an identity index from the FIRST frame's drawRange window, pinning geometry.indexCount to a stale size forever (geometry v never bumps), after which the Dart part-range validator rejected every later window => black frame after ~2s. Fixed in tool/three/src/native_renderer.js _ensureGeometry (skip indices when fullRange && !index) and pinned in tool/three/test/batch_test.js (indexCount=0 + growing-window case). Result: 17.98 -> 119.94 FPS Release.
