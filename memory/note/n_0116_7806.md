# Note: n_0116_7806

THREE r186 feedback batch FIXED (2026-11-02, real-GPU verified): (1) webgl_depth_texture froze at 1 frame with 'frame target stale dimensions (frame=2482x1734, cached=640x360)' — root cause: r186 RenderTarget.setSize() calls dispose(); the R1 dispose listener called nonexistent this._queueDisposal → target de-tracked WITHOUT queueing the kind-7 disposal → re-track reset version to 1 → Dart's per-id version gate (value.version <= current.version) dropped the resized upsert. Fix: _pendingDisposals.push({id, kind: RESOURCE_KIND.renderTarget}) so DISPOSE_RESOURCE precedes the re-upsert in the same packet; now 120 FPS. Dart-side: dispose→same-version re-upsert pinned in js_three_state_test.dart. (2) Untextured modifier/interleaved/backgrounds/smaa/custom-attributes(-points) examples: their prepare.mjs entries had assets: [] while the official module loads textures — runtime error 'no host asset loader is configured'; pinned uv_grid_opengl.jpg, crate.gif (convertToPng), hardwood2_diffuse.jpg, brick_diffuse.jpg, water.jpg, sprites/spark1.png with source sha256s. (3) points2 white cloud: color attr is `ca` (also pointColorAttribute drives vertexColors). (4) raycaster bunny: fbx_proxy used a radius-1 sphere under the bunny's 0.0075 transform (invisible); replaced with offline-indexed Stanford Bunny (tool/three_example/generate_fbx_bunny_geometry.mjs → degrades/fbx_bunny_geometry.mjs, 18253 verts/30338 tris), 116 FPS. (5) TextureLoader GIF fallback via three.canvas2d decodeImage (first frame, static) + runtime.loadAsset strips leading './' on host requests (cache key unchanged). Perf data (disproves QuickJS-dominance): interleaved 48-52 FPS with frameMs 0.9ms (healthy, vsync-ish); custom-attributes-points 100k additive sparkles 16-19 FPS with frameMs only 4.5-6.4ms → GPU fill-bound (100k × ~20px sprites @2482x1734), a fill-efficiency project if pursued. Env: node --test tool/three/test/batch_test.js needs node_modules/three (gitignored symlink → pinned r186 checkout) — native_audio.js imports 'three' since HEAD. Bulk re-prepare ALL examples after any assets/three bundle rebuild or pinned manifests fail prepare_test.
