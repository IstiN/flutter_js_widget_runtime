# Note: n_0099_5439

Dart String.replaceFirstMapped replaces ONLY the first match despite taking a RegExp with global semantics — probe scaffolds that wrap N>1 call-site anchors (e.g. both scene renders in a three.js example tail) must use replaceAllMapped after the hasLength/count guard. Symptom when wrong: half-wrapped probe shows renderErrors==0 while allErrors grows (second call bypasses the module wrapper and throws through the prototype/RAF path only).
