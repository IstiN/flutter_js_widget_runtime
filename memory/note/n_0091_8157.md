# Note: n_0091_8157

js_widget_runtime CRAP ratchet gotcha: crap4dart computes CRAP with the full formula (CC²+CC) for functions listed in coverage/lcov.info with 0% hits, but EXCLUDES functions absent from lcov (shown as N/A). GPU-only encoder code in lib/src/renderer/nodes/three/flutter_gpu_three_backend.dart runs only with a real flutter_gpu context (never in unit tests) yet still appears in lcov at 0% — so such helpers must keep cyclomatic complexity ≤ 3 (CRAP ≤ 12). When adding branches to _ThreeFrameEncoder/_recordShadow-style methods, extract the branching into top-level helpers instead.
