# Note: n_0002_bb8e

Run this repo's gates/tests with the Homebrew Flutter 3.47.1 SDK at /opt/homebrew/share/flutter/bin; pushes go through SSH; golden tests need JSR_QUICKJS_LIB pointing at the built QuickJS bridge.

**By:** [[agent]]
**Date:** 2026-09-03T09:09:13.478155Z
**Area:** [[project|project]]

Local env quirks for running this repo's gates (macOS, this machine;
supersedes the older PATH advice — verified 2026-09-03):

1. SDK: `export PATH="/opt/homebrew/share/flutter/bin:$PATH"` (Flutter
   3.47.1, dart 3.13.1 — repo requires `flutter >=3.47.0` since 0.4.110).
   Do NOT resolve flutter via `which flutter` (~/development/flutter 3.44.4
   may win on PATH) and do NOT prepend /opt/homebrew/bin (that `dart` is
   standalone Dart → `dart run crap4dart` fails with "requires the Flutter
   SDK"). Mixing SDKs corrupts .dart_tool hook kernels ("Invalid kernel
   binary format version"); after a mismatch re-run `flutter pub get` with
   the 3.47.1 SDK.
2. git push over HTTPS to github.com HANGS — origin's pushurl is SSH
   (git@github.com:IstiN/flutter_js_widget_runtime.git, authenticates as
   IstiN). Repo-local git identity: Uladzimir Klyshevich
   <uladzimir_klyshevich@epam.com>.
3. Golden tests need the QuickJS bridge:
   `export JSR_QUICKJS_LIB=~/.pub-cache/hosted/pub.dev/quickjs_runtime-0.1.1/native/quickjs/libquickjs_bridge.so`
   (build via `bash $Q/tool/build_quickjs.sh`).
4. lcov (brew) and jscpd (npm -g) are installed; lcov 2.x needs
   `--ignore-errors empty` for flutter coverage files.
