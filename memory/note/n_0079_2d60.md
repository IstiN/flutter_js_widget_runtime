# Note: n_0079_2d60

THREE Minecraft native performance stack (verified on macOS; full pre-commit green): native_renderer.js uses frame-scoped geometry/material/texture memoization and numeric matrix comparison (~13 ms renderer). The stress adapter, without modifying reference gameplay JS, compacts 686 InstancedMesh matrix reservations from ~2.8 GB to 14.5 MB with transparent regrowth, disposes per-chunk water resources, and uses chunk-AABB plus translation-only bounding-sphere raycast prefilters with upstream fallback. Differential hit tests pass; player.update fell ~38→0.4 ms and long streaming runs hold roughly 37–45 FPS instead of 15.
