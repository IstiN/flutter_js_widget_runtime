# Note: n_0115_31dc

Native THREE Canvas2D host readback can starve QuickJS RAF even when GPU frameMs is sub-millisecond: webgl_loader_texture_lottie's 512x512 canvas at 25 Hz produced only 12–16 presented FPS, while the bounded 192x192 fallback restored about 120 FPS. Profile three.canvas2d rasterization/RGBA round trips before optimizing GPU draw cost; keep frequently updated fallback canvases small.
