# Note: n_0058_1987

Reference game ~/git/references/flutter-kart-gp (MIT, leehack): full 3D kart racer, 12k lines Dart over flutter_gpu + flutter_scene 0.24.3, 100% procedural geometry (no GLB), spline track, drift physics, AI, items, synthesized BGM/SFX; web plays via --wasm (Skwasm). Verdict for js_widget_runtime: NOT reachable today — jsr scene3d lacks (1) custom/procedural mesh upload from JS (biggest gap), (2) multi-touch/analog stick input (only onKey + taps), (3) low-latency SFX (audio_player too slow for arcade), (4) web path (flame_3d renders nothing on CanvasKit web build; kart-gp needs skwasm-wasm). Bridge fps is NOT the bottleneck (107-120 steady). Realistic tier-2 path: Dart-hosted mini-engine (spline/physics/camera/particles in Dart, JS = match logic + items + AI at 10-20 Hz state-sync, like voxel.blocks architecture) ≈ 1.5-2.5 months; a lite 2.5D voxel-kart is possible in 1-2 weeks but visually far below kart-gp.
