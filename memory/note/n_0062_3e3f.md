# Note: n_0062_3e3f

Packed voxel binary lane shipped end-to-end (js_widget_runtime 0.4.171, commit f08188b; fa_craft 0.2.24, submodule commit ddf9fc1). Design: dispatchBinary routes voxel.* binary names into the bridge-owned JsVoxelWorld (mirrors the JSON voxel.* interception); voxel.attach advertises `bin: true` only when the QuickJS backend wired __jsrSendBytes. Shared 'JVXM' envelope (u32 magic 0x4A56584D LE + u32 version=1 + u32 RAW header length + NUL-padded-to-4 header JSON + raw body): voxel.mesh.bin = header {id,key,origin,ni,overlay?} + f32 positions + f32 colors + u32 indices; voxel.blocks.bin = header {id,key,origin,size[,palette,shade]} + RAW block bytes (no base64, ~25% less wire, reuses JSON lane's palette cache + cross-chunk remesh). fa_craft gates on `res.bin === true && typeof jsr.hostCallBinary === 'function'`; JSON paths untouched for old runtimes; __hl/mob/drop resident meshes deliberately stay JSON. Gotchas: (1) example/widgets/fa-craft is a GIT SUBMODULE (IstiN/fa_craft) — commit+push inside it first, then bump the gitlink in jsr; its origin may be AHEAD of the local checkout (was 0.2.23 with a competing voxel.blocks path — rebase onto origin, don't rebase your own tree blindly); (2) tools/goldens.js PATCHES tool/jsr_widget_harness.dart (loadGoldenFonts hook) and does NOT revert it — the leftover patch makes jsr_widget_harness_test's screenshot test hang 10 min; `git checkout -- tool/jsr_widget_harness.dart` fixes it; (3) stale example/widgets/fa-craft/.nyc-src poisons npm test (harness prefers instrumented sources) — rm -rf before test runs; (4) goldens must be compared SAME-machine base-vs-change (checked-in PNGs are from another machine); 0.2.23 vs 0.2.24 captures are byte-identical. fa PR #1621 (lock 0.4.165→0.4.171, branch bump/jsr-0.4.171, worktree-based because another session's WIP blocks checkouts in ~/git/flutter_agent) — CI was still running at report time.
