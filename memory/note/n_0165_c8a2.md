# Note: n_0165_c8a2

three-gpgpu-birds-gltf round-3 fix LANDED (2026-11-05, uncommitted): stock build never ran the GPGPU sim in R1 (sim shaders unrecognized → per-tick lowered blit materials created+disposed, RGBA8 RTs, onBeforeCompile displacement dropped) and BirdGeometry was one static 2.2M-vert merged mesh (56.5MB packet, ~1103ms encode, all birds overlapped at origin → renderer.info triangles=1 frozen blob, 63.9fps probe). Fix = degrades/gpgpu_birds_gltf_cpu_flock.mjs (throw-on-drift byte anchors): (a) GPUComputationRenderer.compute() no-op'd after detection + RT blit reads guarded to initial textures (churn gone); (b) CPU flock: InstancedMesh on the REAL Parot/Flamingo GLB (alternating by frame parity) via DRAW_BATCH, boids with the official zone formulas but 3 xorshift-random neighbor samples per bird per tick (density-proportional; grid-bucket dropped for QuickJS budget), bounds mirror+gravity, pointer-predator lane intact, wing-flap via per-instance roll, matrices at ~30Hz cadence (tickFrame%3), GUI count/separation/alignment/cohesion sliders + OrbitControls untouched. GOTCHA fixed en route: xorshift hash must be >>>0 before %COUNT or negative index → undefined → NaN instanceMatrix (R1 finiteness gate rejects). MEASURED: probe_fps presentedFps 63.9→119.9, frameMs 15.611→0.084, flock coalesces (RMS 398→219 over 13s, all matrices finite); V8 tick ~1.4ms warm (bench) / node boot harness tick frames 4.06ms avg incl JIT, calm 0.27ms; one-time upload 81KB (was 56.5MB). Files: degrades/gpgpu_birds_gltf_cpu_flock.mjs (new), prepare.mjs wiring + cpuFlockDegrade flag, test/gpgpu_birds_gltf_boot_test.mjs (new, decodes DRAW_BATCH payloads), test/birds_probe.mjs (dev probe). prepare_test + controls_gui_test green, reprepare --verify byte-stable. probe_fps needed a probe-target rebuild (allowed for probe only); with the stale Nov-5 binary ALL widgets incl precedent three-batch-lod-bvh timed out presentedFrames=0 — probe lane staleness, not widget.
