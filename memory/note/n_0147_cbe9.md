# Note: n_0147_cbe9

Native macOS face tracking: Swift camera.track hostCall drives Vision VNDetectFaceLandmarksRequest per frame (320-wide capture queue, drop-if-busy); Dart mapper in example/lib/camera_host.dart (faceSignalsFromLandmarks + FaceSignalSmother lerp 0.35, quota 20) emits <=20 approx shapes + lookX/lookY in camera.frame payloads; JS native branch of webcam_host.mjs lerps 0.3 into morphTargetInfluences + eye rotations. Real-Vision probe lesson: Vision region point counts VARY by macOS (6-pt eyes on some versions) - mapper guards must be minimal-count, never exact-count; contour aspect can hit ~1.09 on neutral round faces (cheekPuff gate at 1.12).
