# Note: n_0034_0659

WidgetManifest.fromStorage now degrades wrong-typed fields to fallbacks via the _typedOr helper instead of silently dropping the whole manifest (strict casts in try/catch used to kill it entirely); unknown keys were always ignored harmlessly.
