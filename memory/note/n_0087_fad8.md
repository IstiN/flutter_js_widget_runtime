# Note: n_0087_fad8

Nonblocking native QuickJS is opt-in via JsRuntimeConfig.backendFactory: createQuickjsIsolateWidgetEngineBackend. The factory must receive the final effective config (including JsWidgetRuntimeWidget's wrapped onRender); a preconstructed backend can capture the original no-op callback. The persistent worker owns QuickJS/evaluation/R1 encoding while the main isolate owns JsWidgetBridge, timers/RAF, Promise I/O and GPU hosts. Binary messages copy native bytes before TransferableTypedData handoff. quickjs_runtime >=0.4.8 is required for QuickJS stack-top re-anchoring when Dart migrates a worker isolate across OS threads. Worker ports are generation/source checked and stale spawns are killed to make dispose/restart safe.
