# Note: n_0068_8e67

crap4dart >=0.10.0 (including 0.17.0) cannot currently resolve in this project: it requires xml ^7.1.0, while flutter_svg 2.3.0 via vector_graphics_compiler constrains xml <=7.0.1. The project dev dependency is therefore crap4dart ^0.9.5; a globally activated crap4dart 0.17.0 can still be used for the newer `profile` command. Revisit when the flutter_svg/vector_graphics xml constraint changes.
