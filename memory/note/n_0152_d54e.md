# Note: n_0152_d54e

SOLVED (2026-11-04): webgl_batch_lod_bvh BLACK SCREEN / js_three_batch_csg_regression_test 'official batch LOD BVH presents centered real instances' 0-draws red. ROOT CAUSE (NOT the FrameResources refactor — the Dart lane behaved correctly all along): the prepared widget's facadeWraps.BatchedMesh bound in tool/three_example/prepare.mjs (webgl_batch_lod_bvh entry) clamped maxInstanceCount to 128 but the official module adds 500k instances (`Hi=5e5`) into a 708×708 grid (±1944 units); keeping the FIRST 128 ids = one far grid-corner strip (~x −194…−1244, z −194), outside the origin-targeting camera frustum (camera 0,20,55, far 100) → JS renderer.info.render.calls=0, frame command culledNodeIds=all 10 batch nodes, Dart plan correctly honors JS culling → 0 draws → black. DIAGNOSIS METHOD: prelude-patch THREE.Frustum.prototype.intersectsObject + InstancedMesh.prototype.computeBoundingSphere via ThreeQuickjsExampleHarness sourcePrelude (wrap jsr.exportState to ride along — the example adapter overwrites exportState periodically) to read the renderer's live cull spheres/planes. FIX: wrapper now retains the 128 instances CLOSEST TO WORLD ORIGIN (streaming closest-to-origin with slot replacement: buffer geometryId in a doubling Uint16Array, admit via super.addInstance+setMatrixAt, evict worst via super.deleteInstance — addInstance reuses freed slots; recompute worst from the dist map after each eviction; init _jsrWorstDistance=-Infinity, NOT Infinity, or worstId stays -1 and the first eviction calls deleteInstance(undefined) → 'Cannot read properties of undefined (reading active)' which KILLS the widget boot, surface never mounts, harness.state=null). Reprepare: `node tool/three_example/prepare.mjs webgl_batch_lod_bvh` (manifest records current tree bundle hashes — consistent with the tree-wide bulk-reprepare state; official_module sha pinned/unchanged). Node unit for the wrapper math lives in /tmp/cull_unit.mjs (eval'd against /tmp/jsr-three-r186/build/three.module.js): retained maxAbs 35.75 vs grid half 616, centroid ≈ origin. RESULT: regression test green (10 draws, 2097152 tris = 128×16384 LOD0, 128 instances, envMap>0, uploads flat), FULL flutter battery +1184 ~7 −0 (was +1183 −1).
