# Note: n_0118_67fa

THREE runtime-issue batch 2 verdicts (2026-11-02): (2) webgl_shadowmap_performance NOT hitting ~120fps is GPU-raster-bound, NOT JS/light-bound: presentedFps 44-52 (2 runs + load variance) vs depth-texture AND skining-blending both 119.88 on the same build/window (2978x1734@2x). frameMs (Dart present path) only 0.85ms; headless worker cost pump-bound (<=2.3ms/frame); scene has exactly ONE directional shadow light (1024 shadow map, 0 dropped lights), 601 Horse.glb morph clones (25 animation groups), ~410k tris redrawn in shadow pass (3.6 draws/f) + main pass (6 draws/f) every frame + ~1 geometry re-upload/frame (CPU-evaluated morphs, bounded lane). ~22ms GPU/frame = 44fps ceiling; out of scope, documented. (3) webaudio_timing 'never loads' is BY DESIGN gesture-gating + an app delivery gap: module does getElementById('startButton').addEventListener('click') at eval; facade auto-clicks startButton on first delivered pointerdown + calls JSR.three._resumeAudio (example_adapter.js:810); app audio host requires gesture ('three.audio: AudioContext.resume() requires a user gesture'); asset ping_pong.mp3 IS pinned. BUT JsWidgetRuntimeWidget renders only a CircularProgressIndicator until the first render tree, and the tree only exists after the canvas mounts (appendMainCanvas → JSR.render) which needs the click → pre-tree taps reach NOTHING (loading overlay is IgnorePointer(ignoring:!_ready)=pass-through, widget has no Listener) = gesture-gated examples can never start from the app UI. Documented as app-layer future work (forward pre-tree pointerdown as three.input:main, or render a facade placeholder tree). Dedicated test js_three_webaudio_examples_test.dart 4/4 green (dispatchHostEvent pointerdown → renders, draws>=6, audio resume+play routed). (4) webgl_ubo_arrays ALL WHITE = documented bounded-lane degrade, not a bug: native_renderer.js adaptedShaderDraw has a dedicated UBO-array fingerprint (fragment 'pointLightsCount' + vertex 'vPositionEye') lowering RawShaderMaterial GLSL3 uniform-block lighting to a NEUTRAL (white) MeshBasicMaterial with adaptationWarn 'R1 retains UBO-array geometry with a neutral base material; shader-only light arrays are dropped' (101 warnings logged per run); white plane + white spheres = white-on-white. Runs 119.8fps, draws planned fine; R1 has NO uniform-block/GLSL3 lane (out of scope) — future work: CPU-evaluated per-vertex light array like the timeColorGeometry pattern.
