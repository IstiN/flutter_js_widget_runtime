# Note: n_0072_30fd

Voxel frustum side-plane normals are `tan * forward ± axis` (not `forward ± tan * axis`); the old formula culled partially visible chunks at an incorrect aspect-dependent bound. The 0.4.187 regression uses a mob crossing the right edge at depth 5 / aspect 2 and requires two emitted triangles, then zero when fully outside.
