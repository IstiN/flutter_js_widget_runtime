# Note: n_0051_6324

js_widget_runtime 0.4.133 (commit b0bd285): JsonWidgetRenderer has a new optional onGestureEvent sink — onPanUpdate/onScroll go fire-and-forget through dispatchHostEvent('gesture:<actionId>') (bootstrap routes it straight to handleEvent, no event_done round trip). Reason: the serialized callEvent queue lags behind 60-120 Hz drag/scroll streams under load and the widget 'catches up' after finger release. Hosts building JsonWidgetRenderer themselves should wire onGestureEvent to engine.dispatchHostEvent('gesture:'+id, ...) — otherwise it falls back to onEvent (correct, just queued). Also new universal node prop ignorePointer:true (wraps the built node in IgnorePointer inside _applyUniversalEffects) — overlay labels must use it so look-drags fall through. fa_craft 0.2.5: greedy meshing in game/mesh.js (2D rectangle merge per face direction+slice, axes-aware 16/64/16, winding preserved per CORNERS table, shadeFaces works per-quad unchanged) — 3-10x fewer triangles; plus touch jump pad (held.jumpPad) and ignorePointer overlays.
