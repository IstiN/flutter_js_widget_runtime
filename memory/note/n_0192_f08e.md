# Note: n_0192_f08e

R1 raw-texture lane (tool/three/src/native_renderer.js _ensureTexture): HalfFloat/Float textures are expanded to RGBA8 then CACHED by signature. The float-sampler drop branch must gate on `texture.type === UnsignedByteType && !(data instanceof Uint8Array)` (gpgpu default-type float data), never on the expanded bytes (always Uint8Array) nor on raw data alone (drops expanded results before the cache write = per-frame re-expansion, envmaps_exr 4fps). batch_test 17 pins the graceful-drop side.
