# Note: n_0107_ce53

globalThis.THREE (esbuild IFE exports) has GETTER-ONLY properties: assigning THREE.SomeClass = wrapper silently no-ops in sloppy mode (Node repro: name stays the minified original). Per-example class adaptation must ride the facade binding — prepare.mjs definition.facadeWraps {ExportName: 'Base => class extends Base {...}'} (used by three-materials-matcap to peel normalMap). Other per-example prepare hooks: addonShims (replace a three/addons module, e.g. OutlineEffect pass-through for toon) and compat (extra module evaluated before official_module). lil_gui_adapter now supports bounded addColor (hex textField, typed restore) and NativeGUI.domElement is a no-op style sink.
