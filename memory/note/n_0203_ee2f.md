# Note: n_0203_ee2f

crap4dart local main commit b6f4620 (unpublished) fixes the profiler observer effect and real cross-isolate data loss: nested exits do no I/O, outermost exits write cumulative per-isolate shards (100k-call backstop), and ProfileShardReader merges shards once. Stock 0.30.0/0.30.1 read-merge-write reports can lose counts and synchronously rewrite JSON every 5 exits; do not use them as production timing truth. Local hot-loop benchmark: 23.3s -> 6.7s wall, 15.2s -> 0.9s sys; 813 tests passed. The fix is not yet a pub.dev release.
