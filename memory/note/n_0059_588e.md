# Note: n_0059_588e

Bridge microbench (tool/perf/js_bridge_bench_test.dart, run: `flutter test tool/perf/js_bridge_bench_test.dart`, QuickJS macOS): full hostCall round trip with 100-item transform JSON graph = 0.94 ms/call, 300 = 2.69, 1000 = 9.20 (~9.4 µs/item, linear); same payload as base64-packed Float32 = 0.37 / 1.00 / 3.30 ms (constant ~2.8× faster). Decomposition at 100 items: JS build 0.06 + JS stringify 0.28 + transport/promise floor 0.06 (empty hostCall) + Dart-side jsonDecode×2/dispatch/walk ≈ 0.54 — half the cost is Dart-side decode, incl. the double jsonDecode (envelope in _handleSendMessage + args in bridge dispatch). Fire-and-forget pipelining does NOT rescue JSON (0.94 vs 0.95) — cost is CPU serialization, not latency. Frame budget @60Hz: JSON 5.6% (100 items), 16% (300), 55% (1000); b64 2.2/6/20%. Numbers are QuickJS-interpreter on macOS; device JSC-no-JIT same order, Dart side identical.
