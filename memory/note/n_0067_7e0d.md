# Note: n_0067_7e0d

Held gesture state must not use a no-panUpdate idle watchdog: Flutter emits no onPanUpdate while the finger is stationary, so the watchdog stops a live hold. Keep the last joystick vector until explicit onPanEnd/onPanCancel. This was the iOS fa-craft 'player stops while mobs keep walking' root cause; fixed and regression-tested in fa_craft 0.2.30 (f5c57be).
