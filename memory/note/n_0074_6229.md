# Note: n_0074_6229

VoxelPainter visibility ordering contract: exact far-to-near average-depth sorting is only the initial order. The shared-edge topological pass must retain EVERY nonzero perspective-correct depth relation for actual positive-area screen overlaps, including relations that already agree with average depth; dropping those relations lets unrelated shared-edge constraints reverse the pair and caused rare fa-craft slivers. Screen-disjoint pairs may be rejected with 2D SAT, but bbox/depth proofs must not discard an average-correct real overlap. Never cache depth nearness across different cameras; exact order reuse requires the same camera, size and visible-chunk set.
