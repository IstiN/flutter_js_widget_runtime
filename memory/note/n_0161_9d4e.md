Fix = prebuilt scene + early paint, wired in prepare.mjs EXAMPLES webgl_renderer_pathtracer entry: (1) tool/three_example/generate_ldraw_xwing_scene.mjs (node, uses /tmp/jsr-three-r186 LDrawLoader+LDrawUtils.mergeObject; fetch shim serves the pinned MPD because FileLoader wraps urls in `new Request` which rejects relative urls in Node; needs globalThis.ProgressEvent stub) serializes the merged meshes (19 materials, 806556 verts, LineSegments skipped, NO index/color/uv attrs — LDraw geometry is non-indexed pos+normal only) to example/widgets/three-renderer-pathtracer/ldraw_xwing_scene.bin: 'JLXS' u32 version u32 meshCount, per mesh UNPADDED entry (u32 nameLen utf8, u32 color sRGB hex via material.color.getHex(), f32 emissive*3 working-space, f32 roughness/metalness/opacity, u8 transparent, 4x {u32 count, u32 ABSOLUTE byte offset} for position/normal/color/uv), one alignment pad before the blob of Float32 data; sha256 3f011e53a75fba20ee2d28da999a2f6d70ca4f44258744923b97f17a2a2f133b, 19.36MB.
