# Note: n_0089_ebf0

CRAP ratchet gotcha in js_widget_runtime: code reachable only through real GPU rendering (lib/src/renderer/nodes/three/flutter_gpu_three_backend.dart and its gpu/ part files) shows 0% coverage in the plain lcov run — GPU goldens are skipped without --enable-impeller/--enable-flutter-gpu. At 0% coverage CRAP = CC² + CC, so every function there must stay at CC ≤ 3 (CRAP ≤ 12) or the pre-commit ratchet fails: split dispatch helpers (return early via a second top-level function) and long field-comparison chains into smaller helpers. Functions at 100% coverage get CRAP = CC, so plain comparison chains (e.g. material field comparisons, protocol decoders) must also stay ≤ CC 12 — extract per-part/per-group helpers.
