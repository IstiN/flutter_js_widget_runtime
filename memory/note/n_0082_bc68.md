# Note: n_0082_bc68

For timed macOS THREE/QuickJS benchmarks, disable App Nap for com.example.jsWidgetRuntimeExample (`defaults write ... NSAppSleepDisabled -bool true`) and prevent display locking during input automation. Without it, both a fixed allocation-free arithmetic loop and the Minecraft renderer degraded after ~25 s (native render ~8→40 ms) while standalone QuickJS stayed flat; with App Nap disabled, 35+ s runs stayed ~78 FPS / ~7.8 ms native render. This is host scheduling, not scene growth or QuickJS GC; the stress README documents the benchmark setup.
