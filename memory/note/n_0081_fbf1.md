# Note: n_0081_fbf1

THREE R1 performance protocol: optional FRAME trailer u32 count + nonzero culled node ids is backward-compatible with the 136-byte header; native_renderer culls against projectionMatrix*matrixWorldInverse, Dart skips those draws only in the main pass. Shadow maps are cached by surface contentRevision, dimensions, bias/normalBias and all 16 shadow-matrix values; changing matrix/resources invalidates, cache hits must still bind shadowFrameActive=true. Native bundle is a separate Flutter asset: after node tool/three/build.mjs, rebuild/copy the macOS app assets before judging live culling. Verified live with fresh bundle: 1048→516 main calls and 1.78M→0.88M triangles in the stationary stress scene.
