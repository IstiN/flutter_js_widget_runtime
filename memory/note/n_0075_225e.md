# Note: n_0075_225e

VoxelPainter now defaults to the global world-space BSP in js_voxel_bsp.dart (VoxelDiagnostics.bsp=true; reset preserves the default). Static and dynamic straddling triangles split with world-linear RGB; resident chunk streaming uses batched incremental insertion plus an indexed chunk→nodes prune, and static/dynamic subtree AABBs cull offscreen traversal. This design removes the former per-frame full-order work and full-tree rebuild spikes while walking in fa-craft. Preview ?voxelBsp=0 is the explicit legacy fallback.
