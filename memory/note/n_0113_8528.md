# Note: n_0113_8528

Native THREE multi-view contract: batch every renderer.render() in one setAnimationLoop callback into ONE R1 envelope, with transport sequence advancing once per envelope (not per render pass); manual ArrayCamera renders also own a batch. ArrayCamera expands to bounded scissored subcamera passes (64-pass composite cap); its upstream subcamera.viewport is drawing-buffer pixels, so convert to R1 logical rectangles using the renderer pixel ratio on screen. On host resize call renderer.setPixelRatio(dpr) BEFORE renderer.setSize(width,height): calling canvas.setPixelRatio then renderer.setSize with stale ratio silently resets canvas DPR and produces doubled/offscreen ArrayCamera views.
