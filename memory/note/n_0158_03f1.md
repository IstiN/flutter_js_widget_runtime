# Note: n_0158_03f1

R1 shadow lane status for BatchedMesh widgets: the shadow pipeline exists (diagnostics shadowPipelineAvailable:1, draw plan tracks castShadow, proxy lane copies proxy.castShadow = object.castShadow), but webgl_batch_lod_bvh runs renderedShadowDraws:0 / shadowMapWidth:0 — the widget config never enables shadows, so shadows are absent by config, not by a proven DRAW_BATCH-caster drop. Whether R1's shadow pass renders batch proxies as casters remains UNTESTED (no capture with shadows enabled was made; the experiment was reverted). Do not claim a shadow-pass drop point in lib/src/renderer/nodes/three/ without enabling shadowMap on a widget and capturing.
