# Note: n_0196_e8cf

Round11 native perf status update: postprocessing-dof is fixed at ~63–76fps (was 4–8) by allowing shared-envMap Phong color batches, raw-double-first matrix/color diffs, and retained PER-MATERIAL color/depth batch variants; dof2 ~119fps, interactive cubes/ortho ~84fps. Critical gotcha: a composer color→depth→color tick must NOT reuse one DRAW_BATCH id for different materials — Dart reconciles only the latest version, so earlier RT plans sample black. Each material variant needs its own retained anchor/batch id, all kept in seenNodes with only the current variant visible (batch_test 19). Remaining <59fps clusters: CPU skining (fbx ~32, shadowmap_performance ~40, instancing_dynamic ~16, lod ~20), protoplanet CPU sim ~44, dual-pass stereo/anaglyph/parallaxbarrier ~52–56, plus documented unsupported copyTextureToTexture/md2 GUI cases.
