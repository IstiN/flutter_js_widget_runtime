# Note: n_0125_8ac0

Post-sweep consolidation fixes (2026-11-03): after the six parallel fix agents, full-suite triage found 7 new failures — all fixed. (1) webgl_materials_texture_partialupdate exposed a REAL bug in the copyTextureToTexture lowering: the row copy used texel units on BYTE arrays (RGBA rows copied 1/4 of the row; accidental pass on R8 lanes only) and wrote decoded texels into an ENCODED JPEG destination blob → RangeError at TypedArray.set. Fixed in native_renderer.js: byte-layout guard (data.length must equal w*h*d*4 or w*h*d — else loud ThreeCapabilityError 'encoded texture blob'), matching-texel-bytes guard, row math in byte units. Raw-texel lane (Data3DTexture R8) proven by renderer_copy_test.js 6/6; the JPEG-destination example is a documented bounded gap (needs CPU JPEG decode — future work). (2) webgl_loader_collada_skinning never loaded its model: the EXAMPLES entry in prepare.mjs lacked discoverAssets:true → assets never pinned (long-standing documented failure). Adding the flag now pins stormtrooper.dae (2.2MB, external) + jpg; the XML parse takes ~8s in QuickJS — tests must wait for geometry, not frames. (3) Panorama/kincaden textures externalized >1.5MB now load ASYNC — boot-time textureUploadCount assertions need pumpUntil(textureUploadCount>=N). (4) Harness widgetDirAssetLoader tolerates missing assets.json (empty pin table) and bootSource tests must pass assetLoader: widgetDirAssetLoader('example/widgets/<id>') when their source loads externalized assets. Suite end-state: 1132 passed / 7 skipped / 3 failed (batch_csg official ×2, marchingcubes bound — all pre-existing prior-segment regressions, unchanged), duplication 0.996% (tmp_* diag tests deleted; shared helpers in test/support/quickjs_isolate_backend_factory.dart + running_widget.dispatchThreePointerEvent + _csgFakeEvaluatorSource).
