# Note: n_0080_4cb6

Flutter GPU THREE HostBuffer fix (supersedes the per-payload minimum-alignment note): track the cumulative uniform offset and, before any aligned payload, insert a computed filler if the payload would straddle Flutter's 1,024,000-byte HostBuffer block. Minimum alignment alone is insufficient for the final partial block (observed 512-byte payload at offset 102374, requiring a 256-byte filler). Regression covers 320→512 alignment at that boundary; a >7000-frame macOS GPU soak had zero failed presentations. JsThreeNode movementX/Y still comes from PointerEvent.localDelta, not raw OS deltas.
