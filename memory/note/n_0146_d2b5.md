# Note: n_0146_d2b5

three-morphtargets-webcam web lane: tool/three_example/degrades/mediapipe_web.mjs is the import override for 'https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@0.10.35' — a sync stand-in (FilesetResolver.forVisionTasks / FaceLandmarker.createFromOptions return immediately; the bundle stripped the official awaits) that hydrates the real CDN module via dynamic import() in the background. Camera frames come through the jsr.hostCall('camera.*') pull contract answered on web by example/lib/web_camera_host.dart (wired in example/lib/preview.dart via chainedWith after WebAsrHandler). Gating: installMediapipeWebCompat() only on backend 'webgl2' + worker scope (importScripts); offline/CDN failure keeps the mediapipe_static.mjs stub behavior incl. its exact offline warn. Official mapping/eye math lives as pure exports (BLENDSHAPES_MAP 51 entries, computeEyeScores, applyFaceResult, sanitizeCategories) covered by tool/three_example/test/mediapipe_web_test.mjs; the bundled official animate() loop still does the runtime application. MediaPipe VIDEO mode requires strictly increasing timestamps — same-ts re-detect poisons the graph (async "Packet timestamp mismatch"); the stand-in dedupes per painted frame and stamps monotonically.
