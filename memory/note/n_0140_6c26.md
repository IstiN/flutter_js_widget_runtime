# Note: n_0140_6c26

R1 winding/cull fix (landed, golden-tested): flutter_gpu_three_backend.dart `_threeCull`/`_threeShadowCull` now flip the cull set when matrixWorld.determinant()<0 (three.js frontFaceCW parity). Before: any mirrored scene (scene.scale.x=-1, e.g. webcam examples) back-face culled ALL FrontSide meshes — invisible planes AND the glitched facecap face (missing nose, seams, floating jaw). Regression: test/golden/js_three_mirror_winding_golden_test.dart (0 red px pre-fix, 65536/65536 post-fix).
