# Note: n_0121_8f03

three-example external-asset pipeline: prepare.mjs externalizes assets > inlineMaxBytes (default 1,500,000; CLI --inline-max-bytes) instead of inlining base64. External assets land as raw files in example/widgets/<id>/ named by assetOutputName(url) (e.g. models__gltf__LittlestTokyo.glb) or the pinned `output` name, with a generated assets.json descriptor ({schema jsr-three-example-external-assets-v1, url, file, mime, bytes, sha256}). The adapter (example_adapter.js) resolves those urls via loadAsset (host lane, canonical url, no './'/query) instead of registerAsset; small assets keep the legacy inline-base64 path byte-for-byte. example/lib/three_widget_assets.dart provides the Flutter-side widget-dir asset loader wired in three_example.dart/screenshot.dart; test/support/three_quickjs_example_harness.dart exposes widgetDirAssetLoader for tests. 57/303 widgets ship external assets; the two 50MB+ widgets dropped to 82KB (ifc) and 3.5MB (progressive-lod); first-present latency ifc 3551ms eval→54ms eval + 102ms first-present, lod 8118ms eval→1231ms first-present.
