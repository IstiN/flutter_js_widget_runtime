# Note: n_0076_ce36

JsWidgetRuntimeWidget requires an explicitly supplied QuickJS backend to be constructed with the FINAL effective config: the backend captures config.onRender at construction, so building it with the base config and later config.copyWith(backend: backend) leaves the original no-op render handler, producing R1 uploads but a permanent loading spinner and no attached surface. Prefer the default JsWidgetEngine factory (it auto-selects available QuickJS FFI); the THREE stress runner and js_three_runtime_widget_test cover the working mounting path.
