# Note: n_0127_59c9

Cluster-B buffergeometry family Release findings (post-fix): glbufferattribute 17.98->119.94 (range lane, geometryUploads 1/frame-count); instancing 39.46->92-96 (stable geometry resource identity, per-frame attribute updates instead of new-geometry churn; 2048-instance CPU cap is the lane bound); instancing-billboards 10.49->53-57 (billboard basis cached per view key, Float64Array recompute only when view changes; still upload-per-frame by official time-driven semantics, frameMs ~2.7 = CPU lane, rest is transport); instancing-interleaved 53.95 -> 43.5-52.4 band (3 runs): calls=1 real DRAW_BATCH, batchUploads==frames (official example mutates all 500 instance matrices every frame; upstream re-uploads too — transport-bound, frameMs 0.65-0.91 << 20ms budget, NOT JS-bound); rawshader 119.88 unchanged at vsync. Concurrent capture loops from parallel perf agents cause ~±10% fps variance — re-measure multiple runs before claiming regressions.
