# Note: n_0108_d6fd

Screenshot/three runner (example/lib/screenshot.dart, macOS release): rootBundle.loadString('widgets/<id>/widget.js') for a widget dir MISSING from example/pubspec.yaml assets PENDS FOREVER — the app shows only the Impeller banner, no engine logs, main thread idle (no error). Every new example/widgets/three-* dir must be added to example/pubspec.yaml AND the runner rebuilt; verify presence in the built App.framework/flutter_assets/widgets/<id>/. Same missing-asset class makes headless harness boots look like 'frames=0, no logs'.
