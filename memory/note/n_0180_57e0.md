# Note: n_0180_57e0

R1 many-object perf design (webgl_interactive_cubes*): three QuickJS hot-path layers in tool/three/src/native_renderer.js — (1) _fastNode per-object cache (identity/flag/matrix checks + geometry gate), (2) _materialSnapshotFresh per-material tier in _ensureMaterial (compares ~45 signature inputs vs a WeakMap snapshot taken at last full ensure; any change falls to the full body; skips shader-feedback/_r1ShaderTextures, anaglyph, and active-clipping materials), (3) render walk closure uses object.__r1Vis/__r1Pid expandos instead of Maps (pre-order traverse guarantees parent freshness). Pin: test/js_three_many_object_fast_path_test.dart (tag-keyed frames, must not use array indexes — the harness can emit extra boot frames). Measured Release/macOS: cubes 7.2→18-19 fps, ortho 9.5→14 fps; pointermove storm ~100Hz causes no fps drop (raycast is not the bottleneck).
