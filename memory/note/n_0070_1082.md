# Note: n_0070_1082

VoxelPainter depth ordering contract: sort exact far→near by view depth and use emission order only for exact ties; do not reintroduce quantized depth buckets. Two distinct depths sharing a bucket otherwise fall back to upload order, letting far/fog-colored faces overpaint nearer terrain (fa-craft rotating-camera blue/brown artifacts). test/js_voxel_node_test.dart contains the near-green/far-red bucket-collision pixel regression, verified on VM and Chrome. The old arithmetic-packed bucket-sort hot-path note is superseded; the current renderer batches one drawVertices call over flat typed arrays.
