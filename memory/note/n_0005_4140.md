# Note: n_0005_4140

Root cause of the reported yoclip layout bug was in yoclip itself: _wrapAlignment in yoclip_node_wrappers.dart wrapped alignment-carrying nodes in a factor-less Align that expands under loose constraints (blowing parent columns to full remaining width); fix is Align(widthFactor:1, heightFactor:1), committed upstream as 9f067b7 with the probe promoted to test/js_widget_runtime/yoclip_node_wrappers_alignment_test.dart (yoclip_core 391/391 green).
