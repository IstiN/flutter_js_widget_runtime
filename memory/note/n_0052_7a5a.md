# Note: n_0052_7a5a

VoxelPainter sky-hole artifacts during fast camera swipes were an async-raster aliasing race, NOT winding/clip: canvas.drawVertices sublistVIEWS point at shared typed arrays, and a recorded picture can rasterize AFTER the next paint() overwrote the same arrays. Fix: double-buffer positions/colors/uvs, swap pages per paint. Diagnosis lesson: pixel-probe tests with a geometry-aware scan region (huge plate covering the scanned window) separated real holes from legitimate horizon sky; winding verified via signed-volume parity between mob boxes and terrain mesh (both positive).
