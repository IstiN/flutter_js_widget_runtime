# Note: n_0015_5ab5

Pomodoro widget (example/widgets/pomodoro) implements the cross-repo live state-sync protocol v1 (same protocol as fa_widgets focus-timer; host side = flutter_app JsAppEngine broadcasting storage diffs as reserved 'state.sync' events): reserved storage key '__state' = {v:1, rev, writer, mode, running, remaining, endsAt, completed}; every local transition persists rev=max(localRev,seenRev)+1 with a random per-instance writer id; state.sync adoption ignores own echoes and rev<=seenRev; boot hydrates from __state (falling back to legacy bare 'completed' key) and resolves missed expiries from wall-clock endsAt. Protocol doc: fa_widgets docs/state-sync.md. Keep widget/manifest version bumps aligned when touching this protocol.
