# Note: n_0181_de28

Engine gotchas fixed in native_renderer.js (keep when editing): (1) attributeContentHash must hash exact float32 BITS via Uint32Array view — the old `array[i] | 0` truncation mapped every sub-1.0 element to 0, so fractional vertex edits produced unchanged hashes and frames skipped REQUIRED geometry re-uploads (stale geometry). (2) Snapshot caches must COPY arrays returned by uvTransformElements — it returns the live texture.matrix.elements, which in-place offset/repeat mutations would keep 'equal' to itself (aliasing). (3) JS strict compares are type-strict: store boleans and numbers in the SAME form on both sides of a cache-validity compare (a `? 1 : 0` matcher never matches `!!`-stored booleans).
