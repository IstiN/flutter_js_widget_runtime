# Note: n_0066_03fb

fa-craft «empty world / floating in void» root cause: in js_voxel_blocks.dart, _emitQuad added chunk.origin to vertex positions WHILE also storing origin on JsVoxelChunk, and VoxelPainter._collectChunk added chunk.origin a second time — every chunk at (cx, cz) != (0, 0) was placed at 2× its world offset, tearing 16-block sky gaps between all chunks (and mob/highlight meshes on voxel.mesh stayed at 1× origin, so mobs appeared floating in sky gaps). Fix: _emitQuad emits chunk-local positions (0..sx/sy/sz) matching the voxel.mesh contract; _rasterSlice keeps tone-keyed greedy merging for per-block pixel grain. Also note: flutter_test software rasterizer produces 0-alpha/black images on CustomPaint with drawVertices, so headless pixel tests in flutter_test were bogus — verify 3D/voxel visuals with a real macOS/web runner.
