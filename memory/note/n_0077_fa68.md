# Note: n_0077_fa68

Flutter GPU THREE R1 directional shadows have three macOS/Impeller ABI requirements verified by a real GPU probe: VertexInfo is 320 bytes (Impeller adds 32 trailing bytes after the used 288; member offsets do not move), the shadow-only fragment must declare shadowPosition at explicit layout location 5 to match the main vertex shader, and shadow/main passes need separate submitted command buffers (two render encoders in one Metal command buffer abort). The R1 ABI regression test locks the 320/96/48-byte uniforms; the stress runner's bounded probe requires nonzero 2048² shadow draws and zero GPU/upload failures.
