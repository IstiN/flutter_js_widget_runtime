# Note: n_0114_e298

JsRafScheduler must gate Ticker.start() on `isActive`, not `isTicking`: while the app lifecycle is hidden / frames are disabled, a raw Ticker can be active but not ticking, so a second rAF request used to call start() twice and throw. Regression lives in test/js_widget_bridge_test.dart ('requests while frames are disabled do not restart an active ticker'); resume frames normally and let the existing active ticker continue.
