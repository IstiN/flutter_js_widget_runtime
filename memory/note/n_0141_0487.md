# Note: n_0141_0487

webgl_loader_md2_control FPS fix (landed): 12-16fps → 119-121fps (ProMotion cap). Bottleneck was the JS morph blend in tool/three/src/native_renderer.js _applyMorphTargets: 199 MD2 targets × 6030 floats × 2 attrs × 2 models per frame (~2.8M QuickJS iterations) despite ≤2 non-zero influences + full re-encode/upload + GC garbage (~400KB/frame). Fix: blend only non-zero influences, cache blends per (geometry, influenceKey, frameKey), mark _r1FiniteVersion for the bulk TypedArray.set encode path (bit-compatible floats, strict decoder unchanged). Regression: test/js_three_md2_control_performance_test.dart (byte/upload bounds). Measured in release catalog app, 45s JSR_SWITCH_LOG runs.
