# Note: n_0083_a405

THREE R1 FRAME has backward-compatible optional trailers for independent main-camera and shadow-camera culled node-id sets (u32 count + nonzero ids after the 136-byte header). native_renderer computes separate frusta; Dart skips main-culled draws only in the main pass and shadow-culled draws only in the shadow pass. Shadow cache keys include caster-affecting contentRevision, dimensions, bias/normalBias and matrix; failed shadow submissions invalidate the cache. The native bundle is a separate Flutter asset, so rebuild it and the macOS app before live measurements.
