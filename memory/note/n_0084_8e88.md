# Note: n_0084_8e88

On this machine the Homebrew Flutter 3.47.1 profile AOT tools (`bin/cache/artifacts/engine/darwin-x64-profile/gen_snapshot_{arm64,x64}`) hang in `_dyld_start` even for `--help`; clearing quarantine does not fix them. `~/development/flutter` is now 3.47.4 and its gen_snapshot works: use it for a one-off `flutter build macos --profile`, but run `flutter pub get` with that SAME SDK first (stale hook.dill gives `Invalid SDK hash`) and rerun Homebrew 3.47.1 `pub get` afterward. Keep tests/quality gates on 3.47.1.
