# Note: n_0172_bd2b

three r186 build is SPLIT: build/three.module.js imports './three.core.js' — any standalone page importing three.module.js via dynamic import needs three.core.js served next to it or the import 404s with a misleading "Failed to fetch dynamically imported module" (fetch itself returns 200; the dependency fails). Both are committed at example/web/jsr_three_web.js (module) + example/web/three.core.js (core); build.mjs ensureWebThreeBundle() refreshes them from THREE_SRC when the pinned checkout exists. The hash-verified source is unpkg three@0.186.0 (module sha256 9052042d…812ea).
