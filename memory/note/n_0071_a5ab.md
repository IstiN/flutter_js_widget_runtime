# Note: n_0071_a5ab

VoxelPainter occlusion contract (0.4.187): first sort exact far→near by average view depth with emission order only for exact ties, THEN run js_voxel_shared_edges.dart. Shared-edge triangles are reordered by perspective-correct depth inside their overlap; exact average-depth sorting alone still produced fa-craft brown streaks, and quantized buckets are also forbidden. The web-hot implementation uses an open-addressed table with exact endpoint-pair keys (not 51-bit JS integer map keys or per-edge strings), caches each pair's depth sign across two swap passes, and measured ~15 ms on the 19k-triangle 290° regression frame. Pixel regressions run on VM and Chrome; a 36-angle sweep plus dynamic desktop/mobile passes checked the visuals.
