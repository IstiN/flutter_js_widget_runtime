# Note: n_0053_5d8e

fa_widgets pin-bump flow for external widgets (e.g. fa-craft): edit widgets/<id>/overlay.json (source.commit -> new sha, minRuntime), then `dart run bin/fa_widgets.dart fetch --root widgets` (materializes the pinned tarball into vendor/external/<id>, gitignored) + `validate`, commit "chore: pin <id> to <ver> (repo@sha)" and push to main. The publish-catalog workflow rebuilds the zip, tags <id>-v<ver> with the zip asset, updates the rolling `catalog` release (what apps fetch via releases/latest/download/<id>-<ver>.zip) and mirrors catalog.json into the repo with [skip ci]. fa_craft local clone: ~/git/fa_craft (tests: npm test; CI gate: npm test + npm run crap — nyc needs `npm ci` first).
