# Note: n_0001_b580

flame_3d is VENDORED into js_widget_runtime at lib/src/flame_3d_vendor/ (flame_3d 0.3.0 + the Flutter 3.47 flutter_gpu fix) because hosted flame_3d 0.3.0 does not compile on Flutter 3.47+ and pub.dev forbids git dependencies in published packages.

**By:** [[agent]]
**Date:** 2026-09-03T09:09:13.478155Z
**Area:** [[project|project]]

Details: source is the IstiN/flame fork commit fad05ce (backport of
flame-engine/flame#3995); imports rewritten
`package:flame_3d/…` → `package:js_widget_runtime/src/flame_3d_vendor/…`.
Shader bundles live at assets/flame_3d/shaders/ (pubspec-declared; asset
keys rewritten to `packages/js_widget_runtime/...`). pubspec declares
flame_3d's transitive deps (collection, meta, ordered_set, flutter_gpu).
The vendor dir is excluded from jscpd (.jscpd.json), lcov coverage
(scripts/pre-commit + pr.yml) and crap4dart.yaml. Drop the vendor and
restore hosted flame_3d once upstream publishes a 3.47-compatible release
— checklist in lib/src/flame_3d_vendor/VENDOR.md and AGENTS.md
"Flutter Version / flame_3d Vendoring". The old flame-3.47 branch and
automerge-main.yml were deleted (2026-09, release 0.4.110); CI pins
Flutter 3.47.1.
