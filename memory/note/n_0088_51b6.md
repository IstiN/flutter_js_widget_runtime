# Note: n_0088_51b6

GPU three.js R1 golden tests (test/golden/js_three_r1_golden_test.dart, js_three_r1_orthographic_golden_test.dart) only run with BOTH: `--enable-impeller --enable-flutter-gpu` AND `--dart-define=JSR_THREE_GPU_GOLDEN=true`, plus the Homebrew Flutter SDK (`/opt/homebrew/share/flutter/bin/flutter`). Without the impeller/flutter-gpu flags the backend never becomes ready (diagnostics stuck at backendInitializing: 1, presentedFrames: 0) and both tests fail with "Expected: not null" — this looks like a GPU-contention problem but is just missing flags. Plain `flutter test` skips them (~3 skips in a green full run of 869 tests).
