## What each number is

- Scene: `tool/three/perf/perf_scene.js` (byte-identical on both legs), 9 shared-material boxes over one static 256x256 DataTexture color map, static lights, animation driven by the explicit clock frame. One pipeline per preset via `jsr.three.cinematic.createPipeline` + `setPreset`; nothing asset-like changes between frames.
- Frames: 300 per measurement window, 3 windows per cell, after a QUIET warm-up (frames until compiles/links/uploads deltas are zero for 10 consecutive frames, bounded at 200 — exceeding the bound is a structural failure). Reported p50/p95 are the MEDIAN over the windows (never a best-of-N pick); a measurement is never repeated because a number looked bad.
- Native wall time: one `rt.eval` per frame on the bench_1b wire — QuickJS encode + facade transport + native ANGLE submit, drained flush microtask included. Native CPU: the same frames on `CLOCK_THREAD_CPUTIME_ID` (thread CPU time; excludes scheduler preemption). Transport: the corpus per-command dispatch (the blob-validated mode) — the batched wire currently corrupts large inline texImage2D blobs (flaky BUS error, owned by the native leg fix lane; see docs/angle_1b.md).
- Web wall time: `performance.now` around `pipeline.renderFrame` in the page (JS-side encode + render; the browser submits asynchronously). Web CPU: not observable in-page — reported n/a.
- compiles/links/uploads per frame: deltas of the facade `__stats.used` counters (`compileShader`, `linkProgram`, `texImage2D`, `texSubImage2D`, `texImage3D`, `texSubImage3D`, `compressedTex*`) — the facade call counters, cross-checked against a per-texture attribution wrapper around the context (`countersAgree` must be true on the native leg).
- Offscreen target bytes: the composer read/write targets plus every render target reachable from the passes plus the subframe accumulation target (HalfFloat RGBA of the drawing buffer, cinematic.js ensureAccum descriptor); bytes = width x height x bytes-per-pixel (+ depth attachment when enabled).
- RSS: resident set size of the native driver process via mach `task_info` (TASK_TASK_BASIC_INFO resident_size), which hosts QuickJS, the facade and ANGLE. Web leg: not attributable (multi-process browser) — n/a.
